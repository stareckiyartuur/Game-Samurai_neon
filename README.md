# Samurai Neon: Godot-проект (просмотр анимаций Рэна)

Откройте папку в **Godot 4.6** (бесплатный редактор, godotengine.org): *Import → project.godot*, затем **F5**.
При первом открытии Godot сам импортирует картинки (1–2 минуты).

## Управление
| Клавиша | Действие |
|---|---|
| WASD | ходьба (работает на любой раскладке) |
| Shift | бег |
| ЛКМ | удар катаной, нажатие во время удара продолжает комбо ×3 (выпад → взмах → вращение) |
| Пробел | рывок |
| ПКМ (держать) | защита |
| F | парирование |
| H | попадание по Рэну |
| K | нокдаун: падение → подъём |
| E | следующий эффект из 19 |
| **Tab** | режим просмотра: ↑/↓ выбор из 21 анимации, `,` `.` шаг кадра, P пауза, X отразить |

## Что внутри
```
project.godot            настройки (Compatibility-рендер)
autoload/                inputs.gd (управление), game_state.gd (флаги и отношения, каркас сюжета)
scenes/main.tscn         главная сцена
scripts/arena.gd         арена: изометрический пол, неон, дождь, камера, режим просмотра
scripts/ren.gd           Рэн: состояния и приоритеты анимаций
scripts/anim_library.gd  загрузка anim_data.json -> SpriteFrames
scripts/ui_overlay.gd    подсказки и список анимаций
assets/characters/ren/   184 кадра (общий холст 420×260, точка опоры 210,228), fx/, anim_data.json
assets/portraits/        модель Рэна (4 вида) для диалогов
source_art/              исходные листы
tools/build_ren_assets.py  нарезка листов и сборка кадров (пересобирает assets)
tests/                   автотест (проигрывает все состояния, сохраняет скриншоты)
```

## Как добавить или переназначить анимацию
1. Откройте `tools/build_ren_assets.py`, словарь `ANIMS`: имя анимации, номера кадров боевого листа (`'3-07'` = строка 3, кадр 7), fps, `loop`, `faces` (`right`/`left` — куда смотрит рисунок; `front`/`back` — без отражения).
2. Запустите `python3 tools/build_ren_assets.py` (нужны pillow, numpy, scipy). Кадры и `anim_data.json` обновятся.
3. Новая анимация сразу появится в режиме просмотра (Tab). Чтобы вызвать её из игры, добавьте вызов `play("имя")` в `scripts/ren.gd`.

## Состояние (честно)
- **Работает:** ходьба, бег, комбо из 3 ударов, рывок, защита, парирование, попадание, падение и подъём, 19 эффектов, режим просмотра. Приоритеты: рывок не прерывает удар, ходьба не прерывает удар/урон/падение, урон не прерывает падение. Всё проверено автотестом.
- **Нужно проверить глазами:** направление `faces` у `hit`, `fall`, `getup`, `crawl_up` (ожидается «вправо»); если Рэн падает не в ту сторону, поменяйте `faces` в `ANIMS`.
- **Заглушки/ограничения:** пол и свет временные; ходьба вверх использует кадры «уходит вправо» (0-29…0-46), ходьба вниз/в стороны — HD-кадры ходьбы; бег только вправо (влево зеркалом). Кадры 3-17, 3-19, 4-00, 6-00 склеены из двух и исключены. Один кадр чуть обрезан холстом.
- **Не сделано:** враги, диалоги, мир. Это следующие этапы.
